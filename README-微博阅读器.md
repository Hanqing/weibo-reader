# 微博阅读器

这是一个**仅在本机运行**的静态微博阅读页，使用当前目录中的 `reader-data/` 数据。阅读器不会上传、修改或删除微博数据。

| 项目 | 说明 |
| --- | --- |
| 启动命令 | `node serve.mjs` |
| 访问地址 | `http://127.0.0.1:4173` |
| 停止方式 | 在运行命令的终端按 `Ctrl+C` |
| 重新生成数据 | 在当前目录运行 `node build-reader-data.mjs` |

请不要直接双击打开 `index.html`，因为浏览器会阻止页面读取本地 JSON 数据。启动本地服务后，通过浏览器访问上述地址即可。

页面会先读取最近一部分资料以保持打开速度；点击“载入完整档案”后，可搜索和筛选全部已抓取微博。选择单个博主时，页面会自动装订完整资料库。

## 文件说明

| 文件或目录 | 用途 |
| --- | --- |
| `index.html` | 页面结构 |
| `reader-app.css` | TrustMRR 风格的阅读器视觉与响应式布局 |
| `reader-app.js` | 本地检索、筛选、排序、展开阅读与按年份延迟加载逻辑 |
| `reader-data/` | 由原始 JSON 整理出的索引与按年份切分的数据 |
| `build-reader-data.mjs` | 从 `weibo_raw_data/` 重建 `reader-data/` 的转换脚本 |
| `serve.mjs` | 只监听本机回环地址的静态文件服务 |
